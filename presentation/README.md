# Presentation and live demo

Build the presentation around the research question, controlled comparison,
measurement checks, results, and limitations. Rehearse with the actual testbed
and keep a clearly labeled recording or saved run as a fallback.

The final demo should have a preflight checklist, one documented launch command,
a hard time limit, and safe cleanup. The editable presentation and speaking plan are in
[deliverables](../deliverables/README.md). The draft distinguishes simulated,
namespace and loopback evidence from the pending physical experiment.
