# Reviewed reference evidence

Add a reference bundle only after the team reviews its contents and provenance.
It should identify source and configuration hashes, environment, run validity,
and the script used to reproduce every summary and plot.

Large or unreviewed runs belong in the ignored runs directory. A release may
use separately approved artifact storage with a manifest and checksums.
The [namespace pilot preview](namespace-pilot-2026-11-11/README.md) contains
checked synthetic-traffic diagnostics, compact request records, published
plots, and enough provenance to rebuild the analysis. Its limitations and
adverse outcomes remain visible. It is not primary evidence.
