# Final report

The report should explain the question, related work, testbed, protocol,
measurement validity, results with uncertainty, and limitations. Trace each
figure to a frozen evidence bundle. Include results that miss the feasibility
target and account for invalid runs.

The proposal remains in the course-materials repository. This repository's
experiment protocol is the working specification, not a replacement copy of
the original proposal.

Start with the [related-work comparison](../docs/related-work.md) and
[published bibliography](references.bib). The
[course requirements checklist](../docs/course-requirements.md) separates our
planned evidence from the final rubric and deadlines, which are still pending.
