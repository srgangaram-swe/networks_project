# Decision records

Create a numbered Markdown record when changing a shared interface, measurement
definition, topology, dependency stack, or evidence policy. Include the decision,
status, alternatives considered, consequences, tests, and linked issue.

Do not rewrite an accepted decision to hide a change. Add a superseding record.
The experiment protocol lists decisions still open for team review.

The [RPC companion decision](0004-rpc-companion.md) records how the new workload
fits the current measurement format without changing foreground RTT or the
bounded classifier.
